# Ticket: Redesign the public Units experience

## Main Success Scenario

1. A visitor opens `/units` and sees minimal Unit cards with image, name, and
   commander; supplementary roster and descendant counts appear on hover or
   keyboard focus.
2. The visitor previews a Unit with pointer hover or keyboard focus, then opens
   the Unit using the established public route.
3. The visitor sees a clear Unit identity header and follows visible,
   navigable branches through its descendant hierarchy at desktop and mobile
   widths.

## Assumptions

| Statement | Status | Evidence or decision |
|---|---|---|
| `Unit.imageRef` and `Unit.description` are the available Unit-managed visual/profile fields. | CONFIRMED | Prisma Unit model and Unit management form expose imageRef and description; no new fields are approved. |
| `Unit.commander` is a website User, not a game Player; no automatic public Player-profile link is valid. | CONFIRMED | Prisma relation is to User; SYSTEM.md defines User and Player identities as separate. |
| Current roster size means the number of active `UnitMembership` rows returned by the Players-owned public roster read. | CONFIRMED | The roster contract and `getCurrentRoster` filter `endedAt = NULL`; BCR-20261102-008 preserves that predicate. |
| Card statistics must preserve the existing Direct Unit Performance type partitions and zero-denominator ratio state. | CONFIRMED | The existing all-Units reader returns type-partitioned values and canonical `RatioMetric`; presentation will label the selected partition. |

Allowed final statuses: `CONFIRMED`, `REJECTED`, `ACCEPTED-AS-LIMITATION`.

### Deviations and Known Limitations

- Directory and tree-node details animate on hover/focus; touch devices show
  supplementary counts by default because they lack hover.
- The family tree is wider than the viewport for large organizations and uses
  local horizontal scrolling; the initial view centers on its root.
- Compact Unit cards omit audit-derived statistics, while the established
  full Statistics section remains on detail pages. No automatic
  Commander-to-Player link is presented because those are distinct identity
  domains.
