# Ticket: Refactor Medals into Player and Unit Awards

## Main Success Scenario

1. A RootUnit Award manager defines ordered Player Awards and Unit Awards with
   an image and concise description.
2. An authorized manager grants or removes an Award for a Player or Unit within
   their permitted RootUnit hierarchy.
3. Public Player and Unit pages show current Awards, and the management list
   reports the number of current recipients without storing derived counts.

## Acceptance Criteria

- [x] Existing Medal definitions migrate to Player Awards without losing IDs, RootUnit ownership, names, descriptions, or image references; initial order is deterministic because Medal order was not previously stored.
- [x] Award definitions support category, independent order, image reference, name, and description; Player and Unit orderings are independent.
- [x] Unit and Player Award grants can be created and removed under `MANAGE_AWARDS`; every write revalidates the session, target, hierarchy scope, and Award category server-side.
- [x] Orphaned Player Award grants cannot become undeletable: cleanup is limited to the RootUnit owner or a full-root `MANAGE_AWARDS` manager and cannot grant new Awards.
- [x] A grant is unique per Award/recipient; quantities derive from current grant rows and display zero when there are none.
- [x] Award definitions with current grants cannot be deleted; users receive an explicit validation error.
- [x] RootUnit management presents distinct Player Awards and Unit Awards with the primary order Order, Image, Quantity Awarded, Award Name and accessible descriptions.
- [x] Public Unit pages show current Awards with image/name and accessible descriptions; empty states are intentional.
- [x] Player Awards display as square, transparent image-only medals at rest, slightly overlapped; hover, keyboard focus, or click smoothly enlarges and spaces the active medal while revealing its title and description. Missing images use a bordered placeholder.
- [x] Enlarged medals and details overlay fixed-size slots without pushing the page down; medals overlap by 8px at rest, and there is no divider above Player Awards.
- [x] Remove the remaining Player-header divider and metadata line beneath the
  medals; hover title and description appear without a background rectangle.
- [x] Image behavior follows existing safe HTTPS/site-path references and thumbnail/fallback conventions.
- [x] The Player-to-Units read contract is extended only as needed for membership-scope validation; no Player identity or roster mutation semantics change.
- [x] Existing dirty worktree changes are preserved and integrated.
