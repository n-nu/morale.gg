# Ticket: Replace Battle Structure tree rails with draggable nested pills

## Main Success Scenario

1. An authorized Event manager opens the Battle Structure organizer.
2. The manager understands containment from nested rounded node surfaces rather
   than connector rails and cumulative indentation.
3. The manager can drag a node from its body while controls within that node
   continue to work normally.
4. Existing drop validation and explicit Move controls remain available.

      is draggable.

- [x] Command Groups expand around nested children using rounded containment;
      Atomic Units remain distinct leaf pills.
- [x] Hierarchy rails and repeated deep indentation are removed.
- [x] The full Command Group shell is highlighted as a valid destination.
