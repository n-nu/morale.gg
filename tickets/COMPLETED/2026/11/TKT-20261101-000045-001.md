# Ticket: Redesign Event battle-structure manager presentation

## Main Success Scenario

1. An authorized Event manager opens the Event management page.
2. The manager can quickly distinguish Attacker, Defender, Command Group, and
   Atomic Event Unit nodes and understand their hierarchy.
3. The manager can still create, edit, remove, assign, and move nodes using the
   current actions and drag-and-drop behavior.
4. The organizer remains usable at narrow, tablet, and desktop viewport widths.
