# Ticket: Add tactile depth to Player medals

## Main Success Scenario

1. A visitor opens a Player profile with existing Player Awards.
2. Hovering or keyboard-focusing a medal smoothly reveals shallow depth and
   restrained perspective while the existing enlargement and neighboring-slot
   displacement continue.
3. Pointer movement gently tilts only the active medal; leaving or reducing
   motion restores the flat, accessible presentation.

### Result

Added a reusable, opt-in semi-3D treatment to the Player medal component.
Existing images, sizing, 500ms enlargement, sibling displacement, details,
and actions remain unchanged. Decorative image-depth layers preserve alpha;
pointer tilt is clamped, CSS-smoothed, and applied without per-move React
renders. Keyboard focus receives a default tilt; touch and reduced-motion
users retain the existing accessible interaction, with a 2D fallback where
3D transforms are unsupported.
