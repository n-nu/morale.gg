# Ticket: Minimum runnable Next.js application foundation

## Objective

Create the minimum executable Next.js application foundation required for future morale.gg
feature development. This ticket establishes technical project structure only. It must NOT
implement domain functionality (no Units, Players, Events, Audits, Statistics, auth, database,
or APIs).

## Main Success Scenario

1. A developer clones the repository.
2. The developer installs dependencies.
3. The developer starts the development server.
4. The developer opens morale.gg in a browser and sees a minimal application shell.
5. The developer successfully runs linting, type checking, and a production build.
6. The developer has a clear, documented location where future feature modules can be added.

## Scope Owner

```yaml
scope_owner:
  type: repository
  id: web-app-foundation
```

Rationale: No product module exists yet, and this ticket explicitly excludes all product-domain
modules (Units, Players, Events, Audits, Statistics). The work is cross-cutting repository
scaffolding (project structure, build tooling, base layout) rather than a bounded product module.
Per `AGENT_WORKFLOW.md` §4.4, this is repository-owned foundation work. No `MODULE.md` is created
by this ticket since no module is being established.
