# Ticket: Event Calendar Dispatch-Board Presentation

## Implementation Owner

Developer B — Chandler Lovely (GitHub: ChanMan64)

## Objective

Replace the public event calendar's conventional month grid with the
team-selected "Dispatch Board" presentation: a compact month navigator (day
numbers with per-event colored dots, today highlighted, no grid boxes)
beside the month's events rendered as full dispatch cards (date block, map
banner art, name, local time, opponent, map, event-type accent), each
linking to the event detail page.

This is a GREEN presentation-only change inside the Events module per
`src/modules/events/MODULE.md` AI Working Rules (styling/presentation within
the module). It was intentionally kept out of TKT-20260921-000017, which
excludes unrelated public-browsing redesign. Option C ("Dispatch Board") was
selected from three mockup concepts on the team design canvas.

## Main Success Scenario

1. A visitor (no authentication) opens `/events/calendar`.
2. The month navigator shows the current month's day numbers with colored
   dots on days that have events, and today visibly marked.
3. The month's events render as dispatch cards in chronological order with
   date, artwork, name, local time, opponent and map where present, and the
   event-type accent color.
4. Selecting a card opens that event's public detail page.
5. Month navigation (previous/next) re-renders both the navigator and the
   card list for the selected month.
6. A month with no events shows a useful empty state.
7. Times continue to render in the visitor's local time zone.
